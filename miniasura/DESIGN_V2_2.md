## 0. 范围一句话

把 v1 的"4 场线性战斗"升级为**10 张地图的推图流程**，用**10 个任务**串起来，
任务对话靠**对话系统**播放；主城长出**商店 / 仓库 / 铁匠（占位）**三 NPC。

## 1. 模块与行数预算（全部新文件，engine 只做拆分微改）

| 模块 | 预算 | 职责 | 不做什么 |
|---|---|---|---|
| `dialogue.py` | ≤80 | 解析 dialogue.txt、按序播放（经 io 抽象，CLI/GUI 通用）、跳过/重看 | 不存状态（进度在任务里） |
| `quests.py` | ≤100 | 解析 quests.txt、任务状态机、奖励发放 | 不认识 GUI、不认识地图细节 |

| `save.py` 改 | +20 | schema 4 + 迁移 | — |
| `gm.py` 改 | +25 | quest/map/potion 三命令 | — |

**行数红线**：`engine.py` 拆分后 ≤200 行（验收项）；所有新文件 ≤200。

## 2. 数据文件（全进 assets.mpak，改数据不改代码）

```
dialogue.txt   节本格式: [id] 逐行台词，# 开头为舞台指示（旁白/动作）
quests.txt     key|名称|类型|目标|奖励|前置任务|对话id
               类型: talk(对话) / kill(击杀N只指定怪) / clear(通关指定图)
maps.txt       序号|地图名|战斗怪key|剧情对话id|解锁前置图序号
shop.txt       物品key|名称|价格        （回收价=售价30%，纯数据）
```

**十任务构成**（蓝本 §4 落地）：主线 6（串 10 图的西游记脉络：出世→学艺→闹天宫→
被压→取经起→灵山）+ 支线 3（花果山除妖 / 龙宫借宝 / 结算统计）+ 隐藏 1
（连续输给小妖甲 3 次 → 彩蛋任务）。奖励只发 exp / 药水 / 装备（金币留 V2.3）。

## 3. 契约（延续 V2.1 全部 + 新增两条）

1. 依赖单向不变：`gui_*.py → engine → quests/dialogue/save`，engine 零 Qt 零任务词汇以外的越界
2. **对话播放走 io 抽象**（CliIo/GuiIo 已有），dialogue.py 不知道自己跑在终端还是窗口
3. **任务状态机**：`hidden → available → active → done`，只允许单向推进；
   状态存 `quest_flags`（schema 4），引擎每次战斗胜利/对话结束调用 `quests.advance(event)`
4. **地图解锁**：`maps_cleared` 记录已通图数，跳图请求 > 已通数+1 一律拒绝（fail-closed）
5. schema 4 新增字段：`quest_flags`(dict) / `maps_cleared`(int) / `potions`(dict) / `storage`(list)；
   迁移链 v1/v2/v3 → v4 全不丢档（V2.1 三条迁移用例必须继续绿）

## 4. 主城三 NPC（蓝本 §5 落地）

| NPC | 功能 | 纪律 |
|---|---|---|
| 商店 | 买血瓶(50)/蓝瓶(30) + 白装回收(30% 售价→折算 exp 补偿，金币 V2.3 前临时折 exp) | 价格全在 shop.txt |
| 仓库 | 背包第二页（容量同 [bag] capacity），穿脱换位逻辑复用 gui_bag | 数据搬家不改逻辑 |
| 铁匠 | 占位（V2.4 强化系统入口），本期只弹"打造中"提示 | UI 先行是工程惯例 |

**战斗内用药**：回合菜单加选项 4「物品」，血瓶回 40% maxHP / 蓝瓶回 30 MP，
库存进 schema 4——这是商店购买力的闭环验证。

## 5. 出口验收（七门禁，先钉死再写码）

1. **十任务全通**：自动冒烟跑完 6+3+1，quest_flags 终态全 done
2. **对话可跳可重看**：跳过（输入 s）不推进任务；任务对话可从任务列表重看
3. **推图顺序解锁**：10 图顺序推进；gm 越界跳图被拒（fail-closed 实测）
4. **商店闭环**：买药 → 战斗内用药回血实拍 → 库存扣减；回收白装补偿到账
5. **拆分达标**：`engine.py ≤200 行`、combat.py ≤130、全文件 wc -l 纪律过
6. **回归**：smoke_v20（18）+ smoke_v21（24）全绿 + CLI dev 模式通关
7. **fail-closed**：未知任务 id / gm map 越界 / 仓库满，全给人话报错

## 6. 明确不做（本期红线）

- 金币经济与掉落引擎（V2.3）、强化（V2.4）、音效（永不，除非点名）
- 任务失败/放弃机制——状态机单向，做减法
- 对话立绘/头像——纯文本节奏

## 8. 动工后修订（2026-10-28 实测驱动，均不破验收框架）

1. **隐藏任务触发条件改版**：原设计「连输小妖甲 3 次」实测不可达（Lv14 一刀秒杀，
   永远输不了）→ 改为「败给白骨夫人 1 次」（lose:boss:1）。
2. **死亡改为落盘**：原 v1 行为死亡不存档 → 跨局败北计数永远无法累积，隐藏任务
   机制失效 → 死亡时落盘（HP 回满，叙事为"老猴拖回疗伤"；死亡惩罚本身仍是 V2.4 范围）。
3. **血量成长入 ini**：12 场消耗战下血上限恒 150 必死（探针实测第 9 图阵亡）→
   [growth] hp_per_level = 6；任务奖励装备空部位自动穿上（否则自动流防御恒 0）。
4. **schema 4 增补 kills 字段**：击杀/败北计数需要独立容器（设计 §3 只列了四个新字段）。
5. **rewards.py 独立模块**：engine.py 行数红线（≤200）由奖励发放拆出达成（191 行）。
