# 花果山 · 晨
一块仙石轰然迸裂，你从石缝里蹦了出来。
老猴说：天下妖魔趁乱欺凌猴群，正缺一双铁拳。
# 目光所及，一只逍遥小妖正在蹂躏桃园

[d_map2]
# 水帘洞 · 夜
老猴引你入水帘洞：要翻天庭，先去斜月三星洞学艺。
你盘坐蒲团一夜，心中默诵长生妙诀。

[d_map3]
# 斜月三星洞 · 试炼
须菩提祖师端坐高台：洞前妖物把守，打下山去，方显心诚。
# 一只逍遥小妖拦在山门前

[d_map4]
# 东海龙宫
老龟引路：大圣来借宝？定海神针一万三千五百斤，拿得动便是你的。
虾兵蟹卒却先围了上来。

[d_map5]
# 南天门
玉帝封你做个弼马温——马倌？孙爷爷不伺候！
金箍棒一路打上天梯，天兵败退。

[d_map6]
# 蟠桃园
九千年一熟的蟠桃，香气顺着风飘了十里。
你挑最大的一颗咬下去，只觉得浑身舒坦。

[d_map7]
# 八卦炉
太上老君的炉火烧了七七四十九日。
炉盖炸开那一刻，你带着一身火光跳了出来。

[d_map8]
# 五行山
如来一掌压下，五百年风吹雨打。
直到那个取经人揭去山顶的符咒：往西天去，将功折罪。

[d_map9]
# 流沙河
取经队伍在流沙河畔歇脚，你自告奋勇前探水路。
河底妖气翻涌，两头水妖扑出水面。

[d_map10]
# 白骨洞 · 决战
白骨夫人立在洞中央，笑声像骨头摩擦：小石猴，你的地契在我手里。
一百年的账，今日清算。

你羞愤交加，握紧了拳头。

【隐藏 · 真假美猴王】通关之后，霞光里走出另一个"你"——一样的脸，一样的棒子。
老猴只看一眼便说：假的。
你抡起金箍棒：世间只有一个美猴王。棒子认了主，从此随你的本事一同长进。
