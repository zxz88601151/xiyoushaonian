**核心发现：V2 蓝图 §1~§8 全是"进游戏之后"的事，§0 步骤 1~5（登录链）整个缺失——
而这恰是 learn-lab 六课里 TCLS 外围层的同构点，教学价值极高，必须补。**

## 1. 缺口清单（补什么）

### 1.1 账号与登录 login.py（P0，新增模块）

- `accounts.json`：`[{"user": ..., "salt": ..., "hash": ...}]`，
  哈希 = `hashlib.sha256((salt + password).encode())`。
  **教学点：永不存明文密码**——同构真实客户端的账号外围
- 会话：`session.json`（登录成功写入，登出删除），GUI 重启仍记住"上次登录"
- **伪区服**：区服列表 = 本地存档分组（`saves/<user>/`），让玩家体验
  "选区→进游戏"流程，但零联网（铁律：不做网络）
- 契约：**engine 不认识"账号"**——save.py 的存档路径由外围决定后注入
  （现 save.PATH 硬编码，需改成 `save.set_path()` 或调用参），引擎照旧只读写这一个文件

### 1.2 多存档槽（P0，v1 存档的升级）

- 每账号 3 槽：`saves/<user>/slot1.json ~ slot3.json`
- 槽位列表窗：等级/进度/游玩时长预览 + 删除（带确认）
- **schema 版本化提前落地**：`"schema": 2` + 迁移函数（v1 的 save.json 须能升上来）
- 存档字段全集（schema 2 建议稿）：
  `schema / user / level / exp / hp / mp / attack / gold / inventory / equipment /
  quest_flags / killed / achievements / next / week(周目) / playtime`

### 1.3 窗口路由 app.py（P0，GUI 的骨）

- 登录窗 → 大厅窗（公告+开始）→ 存档槽窗 → 主城窗 → 战斗窗 → 结算窗
- `QStackedWidget` + `show_scene(name)`，每窗只读自己的数据源
- gui.py（v1.2）降级为"战斗窗"，其余按窗拆文件（gui_login.py / gui_hub.py…），
  单文件保持 ≤200 行可读纪律

### 1.4 对话系统 dialogue.txt（P0，任务的前置）

- 数据驱动：`npc | 台词序号 | 内容 | 触发条件`，引擎只管按序播放、点击下一句
- 蓝图 §4 任务表里"主线-对话"型任务全靠它；没有对话系统，10 任务废 3 个

### 1.5 主城三大 NPC（P0，把散件系统串成"游戏"）

- **商店**：`shop.txt`（物品|价格），买药 + 白装回收（回收价 = 售价 30%，写数据不写代码）
- **仓库**：背包的第二页（容量迁移），教"数据搬家不改逻辑"
- **铁匠**：强化入口 UI（功能 V2.4 才实现，先占位——UI 先行是常见工程顺序）

### 1.6 图鉴 + 结算页（P1）

- 武器谱收集度（10 把点亮）+ 怪物图鉴（killed 集合点亮），纯读存档 flag
- 结算页扩展：总击杀/总伤害/playtime（蓝图 §6 已列，建议并入图鉴窗）

### 1.7 设置窗（P1，小而必要）

- 存档管理（导出/删除）、音量占位（0~100，先存不用）、关于页（learn-lab 版权梗）

### 1.8 音效（P2，可整体砍）

- wav + `audio.txt`（事件|文件），Qt QSoundEffect 即可；**建议最后再做或明确不做**——
  v1 YAGNI 精神仍适用，音效不检验任何架构点

## 2. 对蓝图既有内容的补强

1. **GM 调试台提前到 V2.1 首件**：加金币/发装备/升 10 级/跳幕——蓝图 P0 判断正确，
   建议再升一级：做成 GUI 调试面板（仅 dev 构建），调数值没它寸步难行
2. **战斗公式**：加伤害浮动 random(0.95~1.05)（蓝图已有，提醒落 battle.lua 时
   random 归引擎、公式归 Lua——与 v1 掷骰同一契约）
3. **逃跑成功率**：50%−boss 0% 进 ini，不硬编码
4. **金币经济闭环表**（蓝图缺）：来源 = 掉币/任务/回收，去向 = 商店/强化/仓库扩容——
   每期验收时对账"金币有产出也有去处"，防通胀死档
5. **validate.py 清单**（蓝图 §7.3 展开）：武器必有掉落源 / 任务奖励物品存在 /
   经验曲线单调 / 商店物品可购买 / 词条不违反部位限制 / 存档 schema 可迁移

## 4. 明确不做（红线）

- **联网/多人/真实服务器**：伪区服只做本地目录分组——不碰网络是 learn-lab 铁律
- **内购/商城/抽卡**：真游戏有，玩具不做（掉落引擎已经是"抽卡"的全部教育意义）
- **存档加密/防篡改**：明文 JSON 即可，讨论一次原理即可，不实现（过度工程）
